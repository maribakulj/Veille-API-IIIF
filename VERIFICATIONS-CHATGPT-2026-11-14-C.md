## Tests refusés, prudence et problèmes de méthode

1. Aucun appel HTTP de la sonde, aucune lecture des en-têtes `RateLimit`, aucun test de dépassement et aucun contournement. Les **403 constatés par l'outil web** ne sont pas extrapolables à l'environnement `scripts/probe.py` du dépôt.
2. **Une URL déplacée peut être considérée « résolution de la lacune documentaire », mais ne prouve pas que la réponse HTTP précédente soit devenue 200**. Garder trace de l'ancien diagnostic dans `data.json` puis prévoir l'intégration validée.
3. Les informations de la **route CUDL /v1/iiif/** reflètent l'état décrit dans le README ; ce n'est pas une preuve que l'API IIIF publique du portail a été retirée.
4. Le commentaire README « most part requires no authentication » ne s'applique pas à toutes les routes (ex. Darwin authentifiée) et ne vaut pas quota illimité.
5. **P0 prioritaire** : la contradiction des droits d'Edinburgh. Documenter séparément les licences d'objets, le droit de réutilisation de photographies, l'accès API et les politiques de robots.
