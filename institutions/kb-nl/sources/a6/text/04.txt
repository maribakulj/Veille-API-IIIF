 KB python API: Access to National Library of the Netherlands datasets
 Pypi version
 Travis build status
 KB-Python-API is a simple API for Python , the API provides easy access to free and CC-BY-NC-ND datasets provided by the National Library of the Netherlands ( KB ).
 It relies on the back-end infrastructure of the KB which consists of an SRU and OAI-MPH service. The KB Python API makes it easy to interact with historical data,
for more information on the provided datasets and data-rights take a look at the DataServices page of the KB.
 For example usage have a look at the provided example.py file, or consult the /test directory.
 This package is also available from the pypi website.
To do a quick install:
 pip install kb
