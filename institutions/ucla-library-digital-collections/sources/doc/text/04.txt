 IIIF (International Image Interoperability Framework)
 UCLA Library Digital Collections use the International Image Interoperability Framework (IIIF). This standard allows for the rapid delivery of high-resolution digital images over the web. Every item page in our digital collections displays a IIIF logo, which serves as a gateway to interoperable content across participating academic libraries and museums.
 To use UCLA digital content outside of our website in IIIF-compatible viewers, follow this two-step process:
 Step 1: Locate the IIIF Logo
 Look for the blue IIIF logo on the digital collections item page. You can click this logo directly, or drag and drop it into external research tools.
 Step 2: Copy the Manifest URL
 Clicking the logo opens a page of raw JSON code. While you do not need to read the code, copy its web address (URL) from your browser's address bar to paste into external viewers.
 Mirador
 Mirador is a commonly used scholarly viewer for International Image Interoperability Framework (IIIF) content. Its distinctive feature is its ability to display multiple items side-by-side for comparative study. It is pre-loaded here with one content item.
 To try it with multiple resources, you can add another sample item by copying the manifest URL provided below, clicking the + sign, selecting +ADD RESOURCE , pasting the URL into the blank field, and then selecting the item in the load bar. Mirador windows can be dragged into a different order and customized by changing their settings. The best way to learn its functionality is to click and explore for yourself.
 For your own research, you can access the free UCLA Library standalone Mirador viewer .
 Sample Manifest URL to Copy: 
 https://iiif.library.ucla.edu/ark%3A%2F21198%2Fzz0002hp4m/manifest 
 Exhibit
 Exhibit is a sequential storytelling viewer developed by Mnemoscene. It allows users to guide audiences through images and other media from multiple sources by using zoom to frame particular details for annotated commentary. The viewer is compatible with both 2D and 3D IIIF content.
 Click through the title captions below to experience an interactive Exhibit. Note that you can also independently zoom into and view any resource directly within the display window.
 To create your own digital presentations at no cost, visit the Exhibit.so storytelling platform .
 IIIF Cropping Tool
 The IIIF Community and Consortium have many contributors who develop lightweight online tools to make standardized IIIF functions easier. You can use this cropping tool to generate custom image details from any IIIF manifest.
 To try the tool, copy the sample manifest URL below, paste it into the input box labeled "Enter the URL of a IIIF manifest", and click Submit .
 This resource is hosted on GitHub via the Princeton University McGraw Center IIIF Cropping Tool . It does not save content past immediate usage and is intended to help streamline workflows with other tools and platforms.

 Scalar
 Scalar is a free, open-source authoring and publishing platform designed to make it easy for authors to write long-form, born-digital scholarship online. It enables users to assemble media from multiple sources and juxtapose them with text in a variety of ways, requiring minimal technical expertise.
 The platform is IIIF-compatible, allowing users to import IIIF content either as standard linked media or as complete, interactive items within an embedded viewer. Click and scroll through the sample Scalar project embedded below to see how it displays content.
 Scalar was developed for scholarly and educational use with support from the Mellon Foundation and other organizations. Free accounts are available on the Alliance for Networking Visual Culture registration website .
