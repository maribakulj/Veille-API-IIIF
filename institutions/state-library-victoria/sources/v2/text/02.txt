 International Image Interoperability Framework 
 [in-tuh-NASH-uhn-uhl IM-ij in-tuhr-op-uh-ruh-BIL-uh-tee FRAYM-wurk] /ˌɪntəˈnaʃn̩(ə)l ˈɪmɪdʒ ˌɪntərˌɒp(ə)rəˈbɪlᵻti ˈfreɪmwəːk/
 International Image Interoperability Framework (IIIF) is both a set of open standards for delivering images and audio/visual files on the web, and an international community that develops and uses the organisation's APIs. It is supported by many leading cultural institutions that rely on IIIF to share the full depth of their collections.
IIIF is a critical technology at State Library Victoria, and many other GLAM institutions. It enables modern web browsers to display images and audio/visual files with full detail, structure and meta data (think captions, translations, and annotations), supporting features like deep zoom into highly detailed images.
