## Info The BDR Search API is based on [Solr], one of the two most popular indexers in the world, so many developers will be familiar with it, and there are many online resources for how to structure queries (one [example-resource]). It doesn't support all of Solr's query features, but does support many useful ones. In general, the search query should be formatted the same way as standard Solr queries. If the query is badly formatted, a ‘400 / Bad Request’ response will be returned. If the search is successful (even if there are no results), a ‘200 / OK’ response will be returned.
