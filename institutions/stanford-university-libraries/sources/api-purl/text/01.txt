 PURL
 PURL (Persistent URL) is a service that provides a persistent URL to content in the Stanford Digital Repository. We guarantee that content will be available in some form at this URL. The PURL platform is the basis for access and citation of content and uses other APIs provided by the Stanford Libraries including embed and IIIF .
 API
 Persistent, citable access
 The base url used for this service is https://purl.stanford.edu .

 Public XML
 The base url used for this service is https://purl.stanford.edu .
 Summary
 Will return public metadata about the object in an XML representation. Includes the following parts representing a digital object:
 Identifying information
 Object relationship information
 Content information
 Content availability information
 Bibliographic information
 Version information
 Release information
