 Search/Retrieval via URL
 Search/Retrieval via URL (SRU) servers, including the Z39.50 gateway to the Library catalog.
 The Search/Retrieval via URL (SRU) 
 servers provide access to Library data, including the catalog
 and some authority files, via SRU, a standard XML-based
 protocol for search queries which utilizes the Contextual
 Query Language (CQL), a standard syntax for representing
 queries. The various services the Library provides via SRU
 are documented at
 ( https://www.loc.gov/standards/sru/resources/lcServers.html ).
 Among these services is the Z39.50 Gateway to the Library catalog,
 documentation of which can be found at
 ( https://www.loc.gov/z3950/lcserver.html ).
 Most of the data accessible from the Z39.50 Gateway is also
 accessible via the loc.gov APIs.
