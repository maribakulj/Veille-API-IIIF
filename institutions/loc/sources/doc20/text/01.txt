 PPOC - JSON HTTP API
 An API for the Prints and Photographs Online Catalog
 The PPOC - JSON HTTP API is an API for
 exploring content in the Library of Congress's Prints and
 Photographs Online Catalog (PPOC) , a website focused on
 the Library's collection of still pictures, including
 photographs, fine and popular prints and drawings, posters,
 and architectural and engineering drawings. Documentation of
 the PPOC API, which is a work in progress, can be found on
 the PPOC website ( 
 https://www.loc.gov/pictures/api ). Most of the
 content in PPOC is also accessible via the loc.gov APIs.
