 Microservices
 The LOC microservices serve as public interfaces for various features of the LOC. Each feature is represented as a small concentrated API known as a service. This allows users, researchers and developers to target individual features on a piecewise basis.
 Text Services
 API for accessing full text OCR, word coordinates and context snippets on loc.gov
 Image Services
 API for accessing and manipulating images from the Library of Congress.
 Streaming Services
 An audio and video (A/V) delivery API for the Library of Congress.
