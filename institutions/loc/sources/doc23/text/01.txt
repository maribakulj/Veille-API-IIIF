 NLS BARD API
 An API for the BARD service of the National Library Service
for the Blind and Print Disabled.
 BARD, the Braille and Audio Reading Download from the National Library
 Service for the Blind and Print Disabled (NLS), is a web-based service
 that provides access to thousands of special-format books, magazines, and
 music scores. BARD is password-protected, and all files are in an
 electronic downloadable form of compressed audio or formatted braille.
 BARD is operated as a partnership between NLS and its network of
 cooperating libraries in the United States and its territories.
 Use of BARD requires an application detailing the user's eligibility
 for the service be submitted to a
 network library .
 The Bard Public API is an
 application programming interface that allows searches to be performed
 against the metadata for the entire BARD collection. It does not currently
 allow searches to be performed against the text inside an item. Use of the
 API does not require password authentication.
 The documentation for the NLS Bard API is available at
 https://api.nlsbard.loc.gov/ .
