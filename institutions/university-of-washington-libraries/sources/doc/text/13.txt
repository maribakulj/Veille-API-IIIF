 Work with the IIIF Image API 
 Find information about the International Image Interoperability Framework (IIIF) Image API for advanced website customization in CONTENTdm (classic version).
 Work with the IIIF Image API
 CONTENTdm (classic version) uses the IIIF Image API to build its default image display.  Click the double diagonal arrow button on the upper-right corner of the image to see the viewer:
 https://cdmdemo.contentdm.oclc.org/digital/collection/oclcsample/id/64 
 To verify that a CONTENTdm (classic version) image is supported by the IIIF Image API, a request can be made to return a JSON document containing image information, including width, height, and scaling. The CONTENTdm (classic version) image information URL patterns follow the IIIF Image API specification:
 yourCONTENTdmURL/digital/iiif/2/{collection alias}:{record ID}/info.json
 For the example record noted above, the "info.json" URL is:
 https://cdmdemo.contentdm.oclc.org/digital/iiif/2/oclcsample:64/info.json 
 The IIIF Image API is a powerful and flexible service for interaction with digital images. For example, here's a request to generate a JPEG of the entire image at 15% zoom:
 https://cdmdemo.contentdm.oclc.org/digital/iiif/2/oclcsample:64/full/pct:15/0/default.jpg 
 Here is another request, showing a selected detail from the full image:
 https://cdmdemo.contentdm.oclc.org/digital/iiif/2/oclcsample:64/1500,1000,1200,1400/pct:15/0/default.jpg 
 Here is one more example, showing the image resized for use as a thumbnail image:
 https://cdmdemo.contentdm.oclc.org/digital/iiif/2/oclcsample:64/full/150,/0/default.jpg 
 For more information on these and other methods for calling the CONTENTdm (classic version) IIIF Image API service, consult the IIIF Image API specification .
