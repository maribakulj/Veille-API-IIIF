 Welcome
 This documentation is a comprehensive overview of Exhibit and provides all the information you need to get started.
 What is Exhibit?
 Developed by Mnemoscene using the Universal Viewer , Exhibit currently supports IIIF formatted content and provides a range of features including:
 support for high resolution images and 3D models
 easy-to-use editor
 templates 
 scroll or slide-based storytelling
 interactive quizzes
 autoplay kiosk mode
 ‘duplicate’ functionality for sharing and remixing
 IIIF image zoom, search API, authentication API
 password protected urls
 metadata display
 multi-up paged views
 embedding using iframes
 hosted and self-hosted options
 Exhibit is built using:
 Next.js 
 React.js 
 The Universal Viewer 
 Tailwind CSS 
 Firebase 
 Exhibit is supported by the Universal Viewer community. Join the Universal Viewer Slack channel to keep up with new developments and meet our community.
