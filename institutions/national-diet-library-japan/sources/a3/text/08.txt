 NDL Search is a service that allows patrons to search not only for materials available at the National Diet Library but also for information on materials available at other libraries in Japan. When making an inquiry, please verify that the target material is available at from the National Diet Library as described below. 
 Reference: How to find out whether or not a material is available at the National Diet Library If the named "National Diet Library" (red frame) is displayed in the search result list, then the material is available at the National Diet Library.

 Use of Materials from other libraries in Japan 
 The data on materials found by specifying Other Libraries in Japan in your search parameters are provided by other libraries and institutions in Japan that collaborate with the NDL Search. If you wish to use a from another library, please contact the library or institution holding that material. You can verify the libraries and other sources of materials that appear in bibliographic records. A list of linked databases can be found in Linked Databases .

 2 Data in materials that appear in NDL Search search results 
 Correction of data in the materials 
 If you find bibliographic data that is incorrect or data from a different source that has been identified as identical to NDL data, please contact us and provide information on the relevant data using the inquiry form. 
 When you contact us, please provide the following information: 
 URL of the relevant material (e.g., https://ndlsearch.ndl.go.jp/books/R100000002-I031851437) 
 Bibliographic information such as titles and authors of the relevant material 
 Please select Inquiry Content in the inquiry form as follows. 
 For errors in data of a detailed bibliographic record in a page titled Bibliographic ID of National Diet Library, select "About bibliographic or authority data". If the URL of the relevant material is a code that starts with "-i", please select "Technical specifications of NDL Search" (e.g. https://ndlsearch.ndl.go.jp/books/R100000002-I029615097-i32363065) 
 If you find an error in data of a detailed bibliographic record in a page titled Bibliographic ID of National Diet Library and the material is an "Article", please select "About the Japanese Periodicals Index". 
 Inquiries about the use of the API 
 If you wish to apply to use an API , please check the API Usage page and apply using the form below. NDL Search API Application Form 
 If you have any questions about API specifications, please contact us using the following form. Inquiry Form In the "Inquiry Details" column, please select " Technical specifications of NDL Search ". When making an inquiry, please include specific information such as trial examples, search conditions, and URLs.
