Query one of the source-indices directly

Using the endpoint /source one can query a resource directly by its ID from one of the available indices. The format of the returned data is marcXchange, i.e. Marc21 data embedded into a json content type.

Usage

/source/{source_index}/{id}

Name Type Description
{source_index} string source used for looking up ID, see list of indices
{id} string ID of the resources in the corresponding source-index

List of available indices

Source Index Description
swb-aut Data from the SWB
kxp-de14 Data from K10Plus

Example
