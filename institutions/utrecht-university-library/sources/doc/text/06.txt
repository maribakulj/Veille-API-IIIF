 About
 About
 IIPImage is an advanced high-performance feature-rich image server system for web-based streamed viewing and zooming of ultra high-resolution images. It is designed to be fast and bandwidth-efficient with low processor and memory requirements. The system can comfortably handle gigapixel size images as well as advanced image features such as 8, 16 and 32 bits per channel, CIELAB colorimetric images and scientific imagery such as multispectral images and digital elevation maps. 
 Streaming is tile-based, making it possible to view, navigate and zoom in real-time around gigapixel size images that would be impossible to download and manipulate on the local machine. It also makes the system very scalable as the number of image tile downloads will remain the same regardless of the size of the source image.
 Source input images can be in either TIFF, JPEG2000 or JPEG format. Whole images or regions within images can also be rapidly and dynamically resized and exported by the server from a single source image without the need to store multiple files in various sizes.

 Features
 Fast lightweight FastCGI server that can be used with any FCGI-capable web server ( Apache , IIS , Lighttpd , Nginx etc) or used standalone
 Instant dynamic generation of overviews or details at any resolution
 Allows easy viewing of extremely large images (terabyte size) with low processor and memory requirements
 One single image source file, not thousands of small separate files
 TIFF input support (tiled pyramid multi-resolution TIFF)
 JPEG2000 input support
 1, 2, 4, 6, 8, 16 or 32 bits (both fixed and floating point) per channel image handling
 Grayscale, sRGB and CIE L*a*b* color spaces
 ICC profile support
 JPEG, PNG, WebP, AVIF or TIFF output
 Multispectral imaging
 Image stacks
 Image blending
 Multiple client APIs with support for the IIP , IIIF , Zoomify and DeepZoom APIs
 Dynamic watermarking
 Support for Memcached , a distributed memory object caching system
 Secure image distribution: only compressed derivative views of the image are sent to the client. The full-resolution image does not need to be accessible
 Panoramic 3D object image sequences
