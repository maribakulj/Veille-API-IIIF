    Collection image APIs

    How to access the Gallery's collection images.

    The Gallery is in the process of implementing a full IIIF service, serving both images via IIIF Image API URLs, and IIIF collections and manifests using the IIIF Presentation API, as part of its implementation of a new Digital Asset Management System for collection images. Please bear with us as we work to deliver this.

    In the meantime, you can still access images using IIIF Image API URLs. Requests take the form

    https://data.ng.ac.uk/iiif/3/{image PID}/{region}/{size}/{rotataion}/default.jpg

    Image PIDs can be found in the object record Elasticsearch at

    $.multimedia[0][email protected]

    For example, https://data.ng.ac.uk/iiif/3/0M1F-000B-0000-0000/full/max/0/default.jpg returns the uncropped, maximum-size, unrotated image of NG35, Titian, Bacchus and Ariadne.
