 IIIF Presentation API
 Introduction ​ 
 The IIIF Presentation API provides a standardized description of
e.g. the structure, composition or presentation views of digital objects
using a JSON format. These digital objects can be digitisations
of (compound) physical objects or represent born-digital content.
 Implementation ​ 
 Rijksmuseum relies on Micrio to provide
a IIIF Presentation API endpoint for its images.
Please see IIIF Image API for more details
on how to access images of Rijksmuseum artworks.
For some images, Q42 , the creator of Micrio,
has leveraged the IIIF Presentation specification to include detailed
descriptions 
for specific sections of an image.

 There is one production endpoint available.
