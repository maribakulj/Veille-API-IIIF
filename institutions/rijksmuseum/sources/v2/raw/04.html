Data Dumps

Data dumps are available with metadata from various domains in their respective representations.

Multi-domain object metadata download​

This set of files includes resource metadata from the Rijkmuseum collection and library domains. The metadata is represented in the CIDOC-CRM (scoped to Linked Art) and Schema.org conceptual models, and serialized as application/n-triples.

Each file contains the metadata of a single resource. The files are distributed through the following downloadable archives:
