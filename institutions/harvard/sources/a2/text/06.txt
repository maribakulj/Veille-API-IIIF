 FAQ: In-library Public Computer Access to Restricted Images
 By Janet Taylor 
 1 min 
 Add a reaction
 Updated: August 25, 2026
 What has changed?
 As of July 1, 2026, this issue has been resolved. Library visitors without a HarvardKey can access high-resolution versions of restricted Harvard Library digital images from in-library public computers.
 In-library device access to restricted images using the MPS Viewer (Mirador) now works with all browsers when pop-ups are enabled. If a browser's pop-up blocker is active, the restricted image will not display, and the user will be prompted to log in. The login bar now includes help text instructing users to manually enable pop-ups for the browser.
 Who is affected?
 This update benefits Library visitors who do not have a HarvardKey, including visiting researchers, external faculty or students, independent scholars, and other non-Harvard affiliates using public computers in Harvard Library spaces. Harvard affiliates with HarvardKey access were not impacted by the original issue and are not affected by this update.
